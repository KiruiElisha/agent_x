Hosted WhatsApp connection

Send and receive WhatsApp from your own app.

This service holds the WhatsApp session. Your app talks to it over HTTP with an instance id and an access token. Inbound messages are posted to a webhook you choose. It works with any system that already uses those two fields, including apps built for WaClient. Nothing else has to be installed next to your app.

1 Create a client

Enter a short id and your email. You receive an access token and an instance id, shown here and sent to that address.

2 Link the phone

Scan the QR code, or type the pairing code under WhatsApp, Linked devices.

3 Call the API

Set your app’s API address to this site. Paste the instance id and access token. Point the webhook at the URL that should receive messages.
