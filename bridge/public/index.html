WhatsApp API

Send and receive WhatsApp from your own app.

This service keeps the phone session. Your app sends and receives over HTTP. You do not install anything beside the app. Anything that already uses an instance id and an access token, including a WaClient app, only needs this site as its API address.

  1. 1
    Create a client

    A short id and your email. That email is how you sign in again.

  2. 2
    Link the phone

    Scan the QR code, or type the pairing code in WhatsApp under Linked devices.

  3. 3
    Paste two values into your app

    Set the API address to this site. Messages you should receive go to the webhook you register.
